Available source data for the current CSPP C0 manuscript

This companion contains the available public numerical figure inputs and saved table values, not complete raw study datasets. coverage.csv maps all 18 main and supplementary figures/tables. The previously missing public Figure 5/S1/S2/S5 inputs have been recovered and verified. Chinese record-level source data remain unavailable. Values are exported from preserved results, never inferred from plot pixels. See sources/ for provenance and manifest.json for hashes.

Precision, recall and F1 are proportions; delays are seconds, and CPU times are milliseconds. Output delays summarize each method's matched records. Continuous threshold curves are post-outcome sensitivity results, not independently calibrated operating points. Table 3 contains component-wise medians across three seeds, so its medians need not describe one run. CPU timing samples are repeated updates, not independent earthquake observations. No raw-waveform rerun is claimed.

China source data are excluded because the owner does not permit public sharing; reviewer access is also unavailable under the confirmed restrictions. This package contains no Chinese record-level data. Public waveforms must be obtained from their original providers under the providers' terms. No additional third-party data licence is granted by this companion.

The separate CSPP_code_v0.2.0_20261103.zip contains code, frozen models, protocols, these public figure inputs, a source-data verification command and a real public NCSN demo. The later 5,000-record evaluation is not substituted for this manuscript's evidence.

Recovered additions, 3 November 2026
Figure 2: original archived MAT and packet-score CSV, with exported display-scaled ZNE waveforms (701 samples per case), all 480 stored packet probabilities per case and three-case metadata. Time is relative to the reference P arrival. Blank probability values preserve NaN; they are not zero. Waveforms are normalized display amplitudes, not physical-unit acceleration. Vertical plot offsets of 6, 3 and 0 for Z, N and E are not applied to the exported arrays. The plotting x limits are -2.5 to 4.5 seconds. Both successful cases and the missed case are retained.
Figure S2, NCSN: exact join on event ID and network.station.location gives 578 records, 51 unique events and 138 stations. Magnitude and distance agree with frozen scored rows; coordinates and depths come from the original request manifest. The old partial CSV is retained for provenance; use the new Figure_S2_nc_record_metadata.csv for complete NCSN plotting metadata.
Figure S4: 82 eligible catalogue events and 12 replay stations. The same station file supplies the NCSN map in Figure S5; per-station duration bars are now supplied separately below.
Sources/Figure_2_provenance.json retains original source hashes and case-selection rules with obsolete home-directory paths removed. The preserved private archive provenance is not included. No plot-pixel digitization or new model inference was used for these additions.

Final recovered inputs, 3 November 2026
Figure 5: all 2500 original training records. The InstanceGM/K-NET/CWA selections match the frozen training-index NPZ exactly. Record-weighted means and event/station counts match the displayed figure.
Figure S1: GeoNet configuration-selection (1049 records, 97 events), calibration (965 records, 92 events), and ablation (491 records, 64 events) metadata. Station counts are physical network.station codes: NZ.PYZ.20 and NZ.PYZ.21 are two location identifiers at one station. Original record/location identifiers remain intact.
Figure S2: complete TexNet (633 records, 65 events, 44 stations) and NCSN (578 records, 51 events, 138 stations) plotting inputs. Event/station keys match the original scored cohorts; use the *_records.csv files for the complete distributions. Earlier partial files are retained for provenance only.
Figure S5: 1423 NCSN station-date rows and the 24 station/cohort summary rows. Figure bars use eligible_station_days, after validity and startup gating: 701.0000173611111 background and 704.8487210648149 event-day station-days. quality_valid_station_days is also retained, but is not the plotted exposure denominator. Coordinates are geographic longitude/latitude in degrees, depth and epicentral distance in kilometres; magnitude retains provider conventions. Training source indices are indices into the original provider-derived training arrays, not newly assigned row numbers.
