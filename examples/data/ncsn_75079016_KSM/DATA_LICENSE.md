# Public NCSN Example: Data Terms and Attribution

The source is the Northern California Earthquake Data Center (NCEDC), NC network,
event 75079016, station NC.KSM.03, 26 October 2024. The catalogue P pick is the
frozen provider reference, not a newly assigned manual label.

NCEDC's published public-data terms describe a non-exclusive, royalty-free,
non-transferable worldwide licence for use, reproduction and public display,
with acknowledgement of the data centre and providing network. The original
terms govern the waveform and its prepared derivative; this repository does not
relicense them as MIT software or grant additional rights.

- Terms: https://registry.opendata.aws/northern-california-earthquakes/
- Data-centre citation: https://ncedc.org/ncedc_doi_metadata.html (10.7932/NCEDC)
- Network citation: https://www.fdsn.org/networks/detail/NC/ (10.7914/SN/NC)
- Provider: https://ncedc.org/

`metadata.json` includes the exact data request and provenance hashes. The files
are a single public demonstration, not a redistribution of the full study data.
